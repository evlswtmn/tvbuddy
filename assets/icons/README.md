# Extension Icons

Chrome extensions require icons in three sizes:

- **16x16** - Favicon and menu icon
- **48x48** - Extension management page
- **128x128** - Chrome Web Store and installation

## Quick Solution

### Option 1: Use Placeholder Icons (Temporary)

Download simple placeholder icons from:
- https://via.placeholder.com/16x16/667eea/ffffff?text=TV (save as icon16.png)
- https://via.placeholder.com/48x48/667eea/ffffff?text=TV (save as icon48.png)
- https://via.placeholder.com/128x128/667eea/ffffff?text=TV (save as icon128.png)

### Option 2: Create Custom Icons

Use a design tool like:
- **Figma** (free, online)
- **Canva** (free, online)
- **GIMP** (free, desktop)
- **Adobe Photoshop** (paid)

Design tips:
- Use the TV emoji 📺 or create a TV-themed icon
- Use the purple/blue gradient colors (#667eea to #764ba2)
- Keep it simple and recognizable at small sizes
- Export as PNG with transparent background

### Option 3: AI-Generated Icons

Use AI tools:
- DALL-E, Midjourney, or similar
- Prompt: "Simple TV icon, purple and blue gradient, minimalist, app icon"

## Quick Setup (For Testing)

For now, you can test the extension without icons - Chrome will show a default gray puzzle piece icon. Add proper icons later when you're ready to publish.
