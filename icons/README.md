# TV Buddy Icons

This directory should contain the extension icons in PNG format.

## Required Icons

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## How to Generate Icons

### Option 1: Use the HTML Generator (Easiest)

1. Open `generate-icons.html` in your web browser
2. Right-click on each displayed canvas
3. Select "Save image as..."
4. Save each as `icon16.png`, `icon48.png`, and `icon128.png` in this directory

### Option 2: Create Your Own

Create your own PNG icons using any image editor (Photoshop, GIMP, Figma, etc.) with the sizes listed above.

### Option 3: Use a Placeholder

You can use any TV or streaming-related icon from sites like:
- https://www.flaticon.com
- https://icons8.com
- https://www.iconfinder.com

Just make sure to create three sizes: 16x16, 48x48, and 128x128 pixels.

## Design

The default TV Buddy icon features:
- Purple gradient background (#667eea to #764ba2)
- White TV screen with play button
- TV antenna
- TV stand

Feel free to customize the design to your liking!
